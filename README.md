# CS-410 Software Reverse Engineering

## Overview

This repository contains my coursework and projects completed for **CS-410 Software Reverse Engineering** at **Southern New Hampshire University**.

Throughout this course, I learned how to analyze binary applications, examine assembly language, reverse engineer software, convert low-level code into C++, identify software security vulnerabilities, and implement secure coding practices. Each week's assignments built on the previous week's concepts, leading to the completion of two comprehensive reverse engineering projects.

Coming from a construction background, I approached software reverse engineering the same way I approached solving structural problems on a job site. Before repairing a damaged floor, reinforcing floor joists, or troubleshooting a crawl space issue, I first had to understand how the structure was built and determine what caused the failure. Throughout this course, I applied that same methodical problem-solving approach to software by understanding how programs were designed before making improvements or security fixes.

## Course Objectives

This repository demonstrates my ability to:

## Repository Organization

### Week 1 Assignments

Introduced reverse engineering fundamentals by examining compiled programs and understanding the relationship between binary, assembly language, and C++.

### Week 2 Assignments

Continued assembly language analysis while learning how higher-level programming constructs translate into machine instructions.

### Week 3 Assignments

Expanded reverse engineering techniques through additional binary analysis and assembly interpretation exercises.

### Week 4 Assignments

Focused on converting assembly language into readable C++ while documenting program functionality.

### Week 5 - Project One

Applied reverse engineering techniques to analyze a legacy client management application.

Project highlights include:

* Reverse engineered an existing application
* Converted binary code into C++
* Documented program functionality
* Demonstrated understanding of assembly language

### Week 6 Assignments

Focused on identifying software vulnerabilities within intentionally flawed applications.

Skills demonstrated:

* Binary analysis
* Security vulnerability identification
* Binary-to-C++ conversion
* Secure coding concepts

### Week 7 - Project Two

Performed a complete software security assessment of the client management application developed in Project One.

Security improvements included:

* Identifying hardcoded credentials
* Limiting login attempts
* Implementing input validation
* Improving authorization controls
* Preventing invalid menu selections
* Protecting customer information
* Documenting vulnerabilities and recommended fixes

### Week 8 Assignments

Explored modern reverse engineering topics including cloud computing, Internet of Things (IoT) devices, software security, and emerging technologies.

## Lessons Learned

This course strengthened my understanding of how software operates at multiple levels, from compiled binaries to high-level C++ source code. It also reinforced the importance of understanding a system before attempting to modify or secure it.

My previous experience in construction taught me that successful repairs require understanding how something was originally built before making changes. Whether repairing floor systems, reinforcing crawl spaces, or troubleshooting structural issues, the process always began with careful inspection and analysis. That same mindset proved valuable throughout this course when reverse engineering software, identifying vulnerabilities, and implementing secure coding practices.

Completing this course has strengthened both my technical skills and my confidence in software analysis, secure programming, and reverse engineering. These experiences will support my continued transition from construction into software engineering as I complete my Bachelor's degree in Computer Science.
